Selected projects

AutoUVM ICCD 2026

A CUDA Unified Virtual Memory prefetching framework for LLMs that don't fit in GPU memory. 3.1× average speedup (up to 4.7×) across ten LLMs under oversubscription, with no changes to model code.

HybridGen
